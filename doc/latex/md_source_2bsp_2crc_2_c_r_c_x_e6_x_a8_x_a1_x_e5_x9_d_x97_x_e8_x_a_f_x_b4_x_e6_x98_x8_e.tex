\begin{DoxyEnumerate}
\item CRC8校验和占用1字节，\+CRC16校验和占用2字节
\item 验证和追加函数需要确保数据缓冲区有足够空间存放校验和
\item CRC8初始值为0xff，\+CRC16初始值为0xffff
\item 校验表已预计算并存储在模块中
\item 数据长度参数不包含校验和本身的长度 
\end{DoxyEnumerate}
