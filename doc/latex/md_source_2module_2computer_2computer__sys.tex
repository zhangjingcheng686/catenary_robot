本系统实现开发板与小电脑间的数据交互，主要包含视觉数据处理、弹道解算、雷达数据接收和机器人状态反馈等功能。代码基于\+HAL库开发，支持多模式配置。

实时性要求：主循环周期需约等于10ms 坐标系约定：
\begin{DoxyItemize}
\item X轴：初式正方向（可能是）
\item Y轴：初式左侧方向（可能是）
\item Z轴：垂直向上
\end{DoxyItemize}
