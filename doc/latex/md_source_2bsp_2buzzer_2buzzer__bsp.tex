本模块实现了蜂鸣器的初始化、开关控制功能，基于\+STM32的\+TIM定时器外设实现\+PWM波形输出，用于驱动蜂鸣器发声。通过调整\+PWM的频率和占空比，可以控制蜂鸣器发出不同频率的声音。

 功能：

初始化蜂鸣器，启动\+TIM12定时器的\+PWM通道2（\+TIM\+\_\+\+CHANNEL\+\_\+2）。 配置定时器为\+PWM输出模式。 \hypertarget{md_source_2bsp_2buzzer_2buzzer__bsp_autotoc_md19}{}\doxysubsection{\texorpdfstring{2. 蜂鸣器开启}{2. 蜂鸣器开启}}\label{md_source_2bsp_2buzzer_2buzzer__bsp_autotoc_md19}
函数原型：


\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keywordtype}{void}\ buzzer\_on(uint32\_t\ frequency,\ \textcolor{keywordtype}{float}\ duty\_cycle);}

\end{DoxyCode}
 功能：


\begin{DoxyItemize}
\item 设置蜂鸣器的发声频率和占空比。
\end{DoxyItemize}

参数说明：
\begin{DoxyItemize}
\item frequency：频率值（单位：\+Hz），范围为16\texorpdfstring{$\sim$}{\string~}1000000 Hz。
\item duty\+\_\+cycle：占空比（范围：0\texorpdfstring{$\sim$}{\string~}1）。
\end{DoxyItemize}

内部逻辑：
\begin{DoxyItemize}
\item 根据输入频率计算自动重装载值（\+ARR）。
\item 根据占空比计算捕获/比较寄存器值（\+CCR）。
\item 更新\+TIM12定时器的\+ARR和\+CCR寄存器值。
\end{DoxyItemize}\hypertarget{md_source_2bsp_2buzzer_2buzzer__bsp_autotoc_md20}{}\doxysubsection{\texorpdfstring{3. 蜂鸣器关闭}{3. 蜂鸣器关闭}}\label{md_source_2bsp_2buzzer_2buzzer__bsp_autotoc_md20}

 功能：

关闭蜂鸣器发声。 实现方式：调用buzzer\+\_\+on(16, 0)，将频率设置为最低值（16 Hz），占空比设置为0。 \hypertarget{md_source_2bsp_2buzzer_2buzzer__bsp_autotoc_md21}{}\doxysubsection{\texorpdfstring{使用方法}{使用方法}}\label{md_source_2bsp_2buzzer_2buzzer__bsp_autotoc_md21}

\item 开启蜂鸣器 调用buzzer\+\_\+on(frequency, duty\+\_\+cycle)函数，传入所需的频率和占空比参数。例如：
\end{DoxyEnumerate}

\end{DoxyEnumerate}

注意事项


\begin{DoxyItemize}
\item 频率范围：蜂鸣器支持的频率范围为16 Hz到1000000 Hz，超出此范围的值会被限制到边界值。
\item 占空比范围：占空比应为0到1之间的浮点数，超出范围可能导致不可预期的行为。
\item 硬件依赖：本模块依赖\+TIM12定时器的\+PWM通道2，确保硬件配置与代码一致。
